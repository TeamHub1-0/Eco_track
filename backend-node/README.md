# EcoTrack Backend API

The backend service for **EcoTrack**, a waste management and garbage reporting platform. It provides RESTful APIs for communication between the frontend application, database, and AI services.

## Tech Stack

| Technology | Purpose |
|---|---|
| Node.js | JavaScript runtime |
| Express.js 5 | Backend web framework |
| TypeScript | Static typing |
| MySQL | Relational database |
| mysql2 | MySQL database driver and connection pooling |
| dotenv | Environment variable management |
| CORS | Cross-Origin Resource Sharing |
| tsx | TypeScript development execution |
| TypeScript Compiler | Production compilation |

### Architecture Overview

The backend follows a feature-based architecture to organize application functionality.

- **config/** – Application configuration and database connection.
- **features/** – Feature-specific modules, such as authentication and garbage reporting.
- **middleware/** – Express middleware for authentication, validation, and error handling.
- **shared/** – Reusable types, utilities, and common components.
- **app.ts** – Initializes Express, registers middleware, and mounts API routes.
- **server.ts** – Application entry point that initializes infrastructure and starts the HTTP server.
- **test/** – Unit and integration tests.
- **dist/** – Compiled JavaScript output generated by the TypeScript compiler.

## Prerequisites

Before running the backend, make sure you have installed:

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm
- MySQL Server
- Git

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/TeamHub1-0/Eco_track.git
```

### 2. Navigate to the backend directory

```bash
cd Eco_track/backend-node
```

### 3. Install dependencies

```bash
npm install
```

For a clean installation using the committed lockfile:

```bash
npm ci
```

### 4. Configure environment variables

Create a `.env` file in the backend root directory.

```env
# Application
NODE_ENV=development
PORT=5000

# MySQL Database
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_database_password
DB_NAME=ecotrack
```

Replace the database credentials with your local MySQL configuration.

**Important:** Never commit your `.env` file or expose database credentials in the repository.

Use `.env.example` to document the required environment variables without exposing actual credentials.

### 5. Prepare the database

Create the database in MySQL:

```sql
CREATE DATABASE ecotrack;
```

Make sure your MySQL server is running and the configured database user has the necessary permissions.

## Running the Application

### Development

Start the development server:

```bash
npm run dev
```

The development environment uses `tsx watch` to execute TypeScript directly and automatically restart the application when source files change.

### Production Build

Compile TypeScript into JavaScript:

```bash
npm run build
```

The compiled files are generated inside the `dist/` directory.

Start the production server:

```bash
npm start
```

### Type Checking

Check TypeScript errors without generating JavaScript:

```bash
npm run typecheck
```

### Testing

Run unit tests:

```bash
npm test
```

## API Health Check

The backend provides a health-check endpoint to verify that the API is responding.

**Endpoint:**

```http
GET /api/health
```

**Development URL:**

```text
http://localhost:5000/api/health
```

**Successful Response:**

```json
{
  "status": "success",
  "message": "EcoTrack API is running"
}
```

HTTP Status: `200 OK`
